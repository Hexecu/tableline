# Product design

Tableline uses familiar database-workbench patterns: a connection sidebar, a table grid, SQL and schema views, and a compact assistant panel. Keyboard commands, persistent SQL drafts and bounded result pages keep navigation fast. All proposed writes have a separate human review step.

TablePlus was a UX reference during the initial local investigation. That investigation did not complete a reference database browsing session, so it is not evidence of full feature parity. Tableline's source, visual identity and icon are original. Tableline is independent of, and not affiliated with, TablePlus.

The AI provider transport and parts of the release tooling derive from the MIT-licensed [Branchline](https://github.com/Hexecu/branchline) project by the same author. See [third-party notices](../THIRD_PARTY_NOTICES.md).
