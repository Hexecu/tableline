The native file installed by npm has SHA-256 `1fad8f56742362a9a7101ff19753d13dc429baee5009f2acf39756460535cab5`, matching both the [upstream `v2.10.0` macOS arm64 release asset](https://github.com/antoniomuso/lz4-napi/releases/download/v2.10.0/lz4-napi.darwin-arm64.node) and the [upstream CI run's arm64 build artifact](https://github.com/antoniomuso/lz4-napi/actions/runs/31935185318) byte for byte. The npm archive is pinned in Tableline's `package-lock.json` with integrity `sha512-rrP5B4CJkSgHBAZ8jP/xGdXULDjDMF/DiUPxtBdo23CfkIOvf2VYGDF2vWO+1LDFMqlV4Mu4dZWwvOWklP4t4Q==`. That CI run built from the pinned source commit with Node.js 24 and Rust stable, using `yarn install` and `yarn build:release --target aarch64-apple-darwin`. Tableline's signing step subsequently changes the native file's bytes; the npm-installed file is the verified matching input.

To obtain the LZ4 source, download the commit archive above or check out that exact commit from the upstream repository. Its `Cargo.toml` identifies Rust dependencies and its `yarn.lock` identifies the JavaScript build dependencies; the linked workflow gives the build commands. The source tree does not contain `Cargo.lock`, and `Cargo.toml` allows version ranges for some Rust crates. The upstream CI logs show some resolved versions but do not record a complete Rust lockfile, so this manifest does not claim the exact Rust dependency resolution or a byte-identical rebuild of the prebuilt binding. The release notes should point to this manifest beside the binary download and retain access to these exact source references for as long as the binary is offered.

The Databricks SQL JavaScript Thrift backend and FlatBuffers JavaScript runtime are included. Its optional native SQL kernel binary and platform package are excluded; `scripts/verify-package.cjs` checks the package inventory, and `scripts/platform-smoke.cjs` tests the supported backend and LZ4 binding in the packaged app. Other JavaScript dependency versions and npm package integrity hashes are fixed by Tableline's `package-lock.json`; their licenses and source locations remain under their package metadata and `THIRD_PARTY_NOTICES.md`.
